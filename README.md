# Course Project 2 – Video Classification

This project is part of the **Introduction to Deep Learning in Computer Vision** course at DTU. The goal is to classify human actions in videos using a subset of the **UCF-101** dataset.

We explore several approaches for video classification, including **per-frame CNNs, early and late fusion, 3D CNNs, and dual-stream networks using optical flow**. We also investigate the effect of **data leakage between train, validation, and test splits**.
